# AI News Aggregator

A Python project for collecting, ranking, and summarizing AI-related news from multiple sources.

## Getting Started

1. Install Python based on `.python-version`.
2. Create and activate a virtual environment.
3. Install dependencies from `pyproject.toml`.
4. Run the app:

```bash
python main.py
```

## Project Layout

- `main.py` - entry point for the application
- `ai-news-aggregator-code` - core project code placeholder
- `pyproject.toml` - project metadata and dependencies
